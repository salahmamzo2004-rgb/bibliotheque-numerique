# Bibliothèque numérique
Site statique (GitHub Pages). Ouvrir `index.html` via un serveur ou publier le dépôt.
Mise en ligne : installer GitHub Desktop (ou `git`), créer le dépôt « bibliotheque-numerique », y copier tout ce dossier, commit puis push.
Settings > Pages > Branch main / root. Ne pas utiliser « Upload files » du navigateur (limite 25 Mo par fichier / 100 fichiers).
